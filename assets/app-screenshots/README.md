# App screenshots — drop zone

Real Bratrax app screenshots used to build the **Shopify App Store listing images**
and (later) the **`/integrations/shopify` landing page**. These are the *actual*
interface — no rebuilt/replica UI.

## Just dump everything here

- **Bulk-upload everything you've got** into this folder. **Filenames don't matter** —
  don't rename anything. I'll identify each screen and pick what to use.
- **Full resolution** (100% zoom, 2× / retina if you can). Bigger is always better — I crop down, never up.
- **Light theme** (matches the beige Shopify embed), from the **demo account** (`bratrax-test-2`) so there's no real customer PII. Still glance for stray real names/emails.
- **Full-bleed app only** — no browser chrome, address bar, or OS desktop in frame.
- PNG preferred (JPG fine).

I pick the hero shots and cut the float crops myself — you don't need to crop anything.

Each listing slide wants **one big hero shot** + **one or two tight detail shots** to float. If you have extras, dump them too — more is better.
